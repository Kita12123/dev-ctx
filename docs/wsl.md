# WSL

## When to use
- To develop with Linux in Windows PC.
- To deploy application to Linux.

## Getting Started

Additionally, granting sudo privileges to your user can enhance your workflow by eliminating the need to enter your administrator password every time you run a command. You can do this by running the following command in your terminal:
```
sudo gpasswd -a <UserName> sudo
```
>[!Note] After running this command, remember to log out and log back in for the changes to take effect.
