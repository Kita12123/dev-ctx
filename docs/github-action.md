# GitHub Action
GitHub Action is tool in the GitHub. You can define action for evalueate app, output report and routine work.
## When to use
- To evaluate applicatin on repository of github.
- To define action as automatic on github.

## Getting Started
**reference**: https://docs.github.com/ja/actions/get-started/quickstart

Create repository in the GitHub and you can use GitHub Action as following:
1. Access GitHub site and click Your Repository>Tab(Actions)>Button(New workflow).
2. Select a demo file mattched you project type and create action file.
3. Select action created and click Run workflow button.
4. You can see log for running action.
